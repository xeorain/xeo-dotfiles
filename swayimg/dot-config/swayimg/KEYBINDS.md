# Key Bindings for swayimg

| Keybind | Description  |
| ------- | ------------ |
| `q`     | Quit swayimg |
| `Esc`   | Quit swayimg |

## Viewer mode

| Keybind      | Description                         |
| ------------ | ----------------------------------- |
| `Return`     | Switch to gallery mode              |
| `s`          | Switch to slideshow mode            |
| `a`          | Toggle anti-aliasing                |
| `Space`      | Toggle animation                    |
| `t`          | Show/hide text overlay              |
| `f`          | Toggle fullscreen                   |
| `m`          | Mark/unmark current image           |
| `c`          | Toggle chessboard mode              |
| `.` (period) | Next frame                          |
| `,` (comma)  | Previous frame                      |
| `n`          | Next file                           |
| `p`          | Previous file                       |
| `g`          | First file                          |
| `Shift`+`g`  | First file                          |
| `Ctrl`+`n`   | Next directory                      |
| `Ctrl`+`p`   | Previous directory                  |
| `h`          | Pan left by 10 pixels               |
| `Left`       | Pan left by 10 pixels               |
| `j`          | Pan down by 10 pixels               |
| `Down`       | Pan down by 10 pixels               |
| `k`          | Pan up by 10 pixels                 |
| `Up`         | Pan up by 10 pixels                 |
| `l`          | Pan right by 10 pixels              |
| `Right`      | Pan right by 10 pixels              |
| `r`          | Rotate 90 degrees clockwise         |
| `Shift`+`r`  | Rotate 90 degrees counter-clockwise |
| `v`          | flip vertically                     |
| `Shift`+`v`  | flip horizontally                   |
| `i`          | zoom in 10%                         |
| `o`          | zoom out 10%                        |
| `w`          | scale current image to fit width    |
| `e`          | scale current image to fit height   |
| `f`          | scale current image to fill screen  |
| `z`          | scale current image to fit screen   |
| `Shift`+`z`  | reset the scale                     |
| `Ctrl`+`d`   | Delete current image file           |
| `Ctrl`+`r`   | Rename current image file           |
| `Ctrl`+`s`   | Scan QR code from current image     |
| `Ctrl`+`i`   | Invert color on current image       |

## Gallery mode

| Keybind     | Description                      |
| ----------- | -------------------------------- |
| `Return`    | Switch to viewer mode            |
| `s`         | Switch to slideshow mode         |
| `a`         | Toggle anti-aliasing             |
| `t`         | Show/hide text overlay           |
| `f`         | Toggle fullscreen                |
| `m`         | Mark/unmark current image        |
| `g`         | Select first file                |
| `Shift`+`g` | Select last file                 |
| `h`         | Select left file                 |
| `Left`      | Select left file                 |
| `j`         | Select lower file                |
| `Down`      | Select lower file                |
| `k`         | Select above file                |
| `Up`        | Select above file                |
| `l`         | Select right file                |
| `Right`     | Select right file                |
| `n`         | Scroll down one page             |
| `p`         | Scroll up one page               |
| `i`         | zoom thumbnails in by 10 pixels  |
| `o`         | zoom thumbnails out by 10 pixels |
| `z`         | set thumbnail size to 200 pixels |
| `Ctrl`+`d`  | Delete current image file        |
| `Ctrl`+`r`  | Rename current image file        |
| `Ctrl`+`s`  | Scan QR code from current image  |
| `Ctrl`+`i`  | Invert color on gallery          |
